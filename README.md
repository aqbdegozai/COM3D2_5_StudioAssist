# COM3D2_5 Studio Assist 1.0.0

COM3D2_5の公式撮影スタジオで、キャラクター選択や画面の整理、撮影前の微調整をしやすくするプラグインです。

## 導入

1. [Releases](https://github.com/aqbdegozai/COM3D2_5-/releases) から `COM3D2_5_StudioAssist_1.0.0.zip` をダウンロードします。
2. ZIPを展開し、中の `BepInEx` フォルダーを `COM3D2x64.exe` と同じ場所にコピーします。
3. 公式撮影スタジオで **左Shift＋F6** を押すと補助パネルが開きます。もう一度押すと閉じます。

## できること

- **Tabキー**を押している間、キャラクターをクリックで選択できる範囲を枠で表示します。
- スタジオのウィンドウを100％・75％・50％・25％に切り替え、位置と倍率を記憶します。
- 瞳の向きや大きさを調整できます。対応する顔パーツでは、ハイライトの大きさ・角度・位置も調整できます。
- 公式の移動軸に名前や用途を表示し、どのキャラクター・オブジェクト・ライトを動かすか見分けやすくします。
- 髪とスカートの当たり判定を微調整できます。脚で押し上がったスカートの形も保持できます。←まだ完全ではありません
- 頭と首の接点を回転させ、頭の角度を調整できます。
