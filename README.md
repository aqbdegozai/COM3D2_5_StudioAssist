COM3D2.5 撮影スタジオ補助 v1.0.1

[v1.0.1 の配布 ZIP](https://github.com/aqbdegozai/COM3D2_5_StudioAssist/releases/tag/v1.0.1)

## 導入
1. ZIP を展開し、中の BepInEx フォルダーを COM3D2x64.exe と同じ場所にコピーします。
2. 公式撮影スタジオで「左Shift＋F6」を押すと補助パネルが開きます。もう一度押すと閉じます。

## 操作
- 従来の公式スタジオでは、Tab を押している間、メイドの選択枠が表示されます。枠内をクリックすると、そのメイドを選択できます。
- ウィンドウの倍率は 100％・75％・50％・25％から選べます。位置と倍率は次回起動時にも引き継がれます。
- 瞳の向きと大きさを調整できます。対応する顔モデルでは、ハイライトの位置・角度・大きさと右ウインクも調整できます。
- 「接触による押し上げを保持」をオンにすると、脚で押し上がったスカートの形を保持できます。
- 髪とスカートの当たり判定を調整できます。従来の公式スタジオでは、髪とスカートにかかる重力の向きを矢印で確認できます。
- 従来の公式スタジオでは、移動軸のラベルで操作対象を確認できます。
- 「首と頭の接点を回転」を使うと、頭の角度を調整できます。
