# COM3D2_5_StudioAssist-
COM3D2_5の公式撮影スタジオで、キャラクター選択や画面の整理、微調整をしやすくするプラグインです。
COM3D2_5 撮影スタジオ補助パネル

導入
1. ZIPを展開し、中のBepInExフォルダーをCOM3D2x64.exeと同じ場所にコピーします。
2. ゲームを起動し、公式撮影スタジオで［左Shift＋F6］を押すと補助パネルが開きます。もう一度押すと閉じます。

できること
・Tabキーを押している間、キャラクターをクリックで選択できる範囲を枠で表示します。
・スタジオのウィンドウを100％・75％・50％・25％に切り替えられます。位置と倍率も記憶します。
・瞳の向きと大きさ、対応する顔パーツではハイライトの大きさ・角度・位置も調整できます。
・公式の移動軸に名前や用途を表示し、どのキャラクター・オブジェクト・ライトなどを動かす軸か見分けやすくします。
・髪とスカートの当たり判定を少し調整できます。スカートが脚で押し上がった形を保持することもできます。
・頭と首の接点を回転させ、頭の角度を調整できます。
